
## Project Title**  
**" Wireless-Connected Homelab: Configuring Cudy TR7300 in WISP Mode for Network Isolation and Testing"**

---

### **Project Description**  
Set up a dedicated homelab network using a Cudy TR7300 router in WISP (Wireless ISP) mode to connect wirelessly to the primary Bell Fibe 4000 router. This created an isolated environment for practicing network analysis with Wireshark, enabling safe traffic capture and monitoring without affecting the main network.

---

### **Key Tasks & Achievements**
- Performed factory reset and reconfigured router via admin panel (`192.168.10.1`)
- Configured **WISP mode** to establish wireless uplink to Bell Fibe 4000
- Enabled **Wi-Fi broadcasting** and disabled hidden SSID to restore client access
- Set up **dual-band Wi-Fi (2.4GHz & 5GHz)** with WPA2/WPA3 security
- Connected homelab devices via **Ethernet and Wi-Fi**, ensuring stable performance
- Enabled **USB sharing** for centralized storage and lab data logging
- Verified full connectivity and began packet capture using **Wireshark** for learning and troubleshooting
